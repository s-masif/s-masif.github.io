# Project page: Unlearning by Subtraction

Self-contained static page for GitHub Pages (no Jekyll front matter, so Jekyll copies it as-is).

- `index.html`: the project page
- `demo.html`: interactive two-gate demo (also embedded in the page via `demo.html?embed=1`)
- `assets/`: figures (PNG for the page, SVG versions of the new figures for slides/papers)

Install: copy this `exact-fgu/` folder to the root of `s-masif.github.io`, commit and push.
The page is then served at https://s-masif.github.io/exact-fgu/

Before making it public, update: the Paper and Code buttons (currently "coming soon"), the author list,
and the BibTeX entry. Numbers and figures come from the recorded experiment logs.
